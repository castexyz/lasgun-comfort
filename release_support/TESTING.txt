LOCAL COMMIT PRIVACY

This repository uses an explicit file allowlist in `.gitignore`. New files are
ignored until reviewed and added to that allowlist. Do not force-add logs,
screenshots, credentials, game source, dependencies or generated archives.

After cloning, enable the local commit guard from the repository root:

    git config --local core.hooksPath .githooks
    git config --local user.useConfigOnly true

Set `user.name` to your public GitHub handle and `user.email` to the exact
GitHub noreply address from your GitHub email settings. Local setup leaves
both unset explicitly so a personal global identity cannot leak into commits.
Run `python scripts/check_commit_privacy.py` to check the staged snapshot.
The hook requires Python 3 and checks both author and committer email at commit.
It scans all indexed files, including force-added files, without printing
matched secret values. It cannot guarantee detection of every possible secret
or prevent deliberate hook bypasses. Recheck before any push.


DIAGNOSTIC DETAILS
Audio logs use the prefix "Audio 0.5:". Each settings batch has a limit of
120 lines plus its limit notice; changing a setting starts a new batch.
Logs report matched shots, gain calls, playback timing and restoration. A
successful native call does not prove that the audible output changed.
Individual-shot gain restores after tracked shots end, before other non-shot
events routed through the hook, on settings changes, source removal, disable
and unload. Starting the next Helbore charge does not restore gain early.
If a native API fails, the original firing events continue.
